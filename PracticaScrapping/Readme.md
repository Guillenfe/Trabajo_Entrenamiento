# Proyecto: Scraping de Cine con LLM

## Descripción

Este proyecto realiza un **scraping dinámico y elaborado** de la página de FilmAffinity de la película *Forrest Gump (1994)* usando **Playwright**.  
El contenido extraído (título, sinopsis, valoración y reparto) se utiliza para generar un **resumen crítico automático** mediante un modelo LLM (Google Gemini u OpenAI).

---

## Objetivos de la práctica

1. Practicar **scraping avanzado** con Playwright (no BeautifulSoup).  
2. Extraer información **relevante y estructurada** de una página de cine.  
3. Integrar la información obtenida con un **modelo de lenguaje LLM**.  
4. Generar un resumen automático en **formato Markdown**.  
5. Realizar un **trabajo de contexto** útil en un tema real (cine).
