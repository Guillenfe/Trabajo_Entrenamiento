# 📋 Requisitos y Ejecución

## 🔧 Dependencias Necesarias

Para ejecutar este script solo necesitas instalar:

- **Selenium** - Framework de automatización web
- **Chromium** - Navegador web
- **Colorama** - Para poner colorcitos a python

## ▶️ Ejecución

El script se ejecuta de manera **interactiva** desde la terminal:

```bash
python Reseñas'Cortas/Largas'.py
```

- ✅ No se requieren dependencias adicionales
- 🔍 Si encuentras problemas de dependencias, consulta con la IA o Internet
